# Third-party factual data notices

`public/data/reference-facts.js` contains a curated factual snapshot. The application uses these facts to construct original MCQ wording and transparent recall-practice variants, **not** to imply that any items were sourced from an official job exam.

## Country/capital/continent/ISO data

Selected and normalized from [samayo/country-json](https://github.com/samayo/country-json), © 2015 Samson Daniel, under the [MIT license](https://github.com/samayo/country-json/blob/master/LICENSE). Some entries were deliberately excluded because capitals, names or political classifications were ambiguous, stale or transitional. Facts should be independently checked if used for a high-stakes examination.

## Periodic table reference facts

Element names, symbols and atomic numbers checked against [Bowserinator/Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON) (original dataset attribution: Wikipedia, [CC BY-SA 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/)). Only factual names, abbreviations and atomic numbers are used; descriptions, images and expressive passages have not been copied. Attribution and the license are provided here for transparency. Changes to the reference table include selecting the established 118 elements and constructing our own exam-practice wording.

Neither source is an official BUET, BPSC, bank or recruiting-agency examination question bank.
